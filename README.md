# PINN coursework

Featured on the Youtube video [Undergraduate Computer Science at Oxford](https://youtu.be/0RpsGWnhV5Q?si=rW84NSPHkeCmq5nz/). This repo has PINN implementation exercises and related experiments (`exercises.ipynb`) as well as a one-pager with notes on the course and solution strategies (`PINN.md`).

To run: `uv sync` then just run the exercises with the associated runtime.
